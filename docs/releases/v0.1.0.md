The first version of USBloom makes USB device topology and descriptors
browsable in a native desktop interface.

- Follow devices through nested hubs, with automatic hotplug updates.
- Explore configurations, interfaces, alternate settings, and endpoints.
- Read decoded USB classes alongside their raw values.
- Select and copy data with native context menus on macOS.
- Save and open device snapshots; follow system light or dark appearance.

### Download

`USBloom-0.1.0-macos-arm64.dmg` is for Apple Silicon Macs. Open the disk
image and drag USBloom into Applications. The package has no Developer ID
signature and is not notarized. macOS may block its first launch; after
attempting to open it, use **System Settings → Privacy & Security → Open
Anyway** if you trust the downloaded build. See the included README.

macOS has been tested with real USB hardware. Windows and Linux pass
build checks but do not have validated installers or runtime support in
this release. Intel Mac downloads are not included.

### Source and integrity

`USBloom-0.1.0-source.tar.gz` contains the exact application source,
lockfile, build scripts, and all locked dependency sources, including the
cyme patch. It includes instructions for an offline Cargo build.
`SOURCE_REVISION` identifies the source commit. `SHA256SUMS` covers the
release files; verify with `shasum -a 256 -c SHA256SUMS` after downloading
all listed files.

USBloom is GPL-3.0-or-later. The application bundle and disk image include
its license and third-party notices. Snapshots may contain device serial
numbers; review them before sharing.
