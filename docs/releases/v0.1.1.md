This update fixes window startup and expands native build coverage.

- Align macOS traffic-light controls with the toolbar on first launch,
  without requiring a window resize.
- Use the GUI subsystem for Windows release builds, avoiding an extra
  console window when launching the executable.
- Check native Windows ARM64 and Linux ARM64 builds in addition to x64.
  Both ARM guests have startup smoke checks; physical USB passthrough and
  complete window interaction remain unverified.
- Update GitHub Actions to Node.js 24-compatible releases.

### Download

`USBloom-0.1.1-macos-arm64.dmg` is for Apple Silicon Macs. Open the disk
image and drag USBloom into Applications. The package has no Developer ID
signature and is not notarized. See the included installation notes.
Windows and Linux installers are not included.

### Source and integrity

`USBloom-0.1.1-source.tar.gz` contains the matching application source,
lockfile, build scripts, and all locked dependencies, including the cyme
patch. It supports an offline Cargo build. `SOURCE_REVISION` identifies
the commit, and `SHA256SUMS` covers every release asset.

USBloom is GPL-3.0-or-later. The application bundle and disk image include
the license and third-party notices.
