# Install USBloom on Linux

Download the **x64** or **ARM64** archive for your computer. Extract it,
then open **usbloom**, or run `./usbloom` from the extracted folder.

These builds target Ubuntu 24.04 and compatible distributions with
glibc 2.39 or newer. On Ubuntu, install any missing desktop libraries with:

```sh
sudo apt install libxcb1 libxkbcommon0 libxkbcommon-x11-0
```
