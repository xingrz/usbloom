# Install USBloom

This build requires an Apple Silicon Mac running macOS 12 or later.
Compatibility with older macOS versions has not been tested on hardware.

1. Drag USBloom into Applications.
2. Eject the USBloom disk image.
3. Open USBloom from Applications.

This first build has no Apple Developer ID signature and is not notarized.
If macOS blocks it, attempt to open the app once, then go to **System
Settings → Privacy & Security** and choose **Open Anyway** for USBloom.
Only do this for a download whose source you trust. System-wide security
settings do not need to be disabled.

Browse the tree on the left and select a device to inspect its interfaces
or descriptors. Connecting or disconnecting a device updates the tree
automatically. USBloom observes devices without changing their USB
configuration.

The matching source archive and SHA256 checksums are available alongside
this download on the project's GitHub Releases page.
