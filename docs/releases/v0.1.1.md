USBloom now includes downloadable packages for macOS, Windows, and Linux.

- Windows and Linux ZIP/tar.gz packages for both x64 and ARM64.
- Platform-aware titlebar controls and scrollbars, with rounded Linux
  client-decorated windows.
- Desktop scrollbar preferences on macOS and Windows, and available
  desktop settings through the Linux Settings portal.
- Correct macOS traffic-light placement at startup and no extra console
  window when launching Windows builds.

### Download

| Platform | Package |
| --- | --- |
| macOS · Apple Silicon | `USBloom-0.1.1-macos-arm64.dmg` |
| Windows · Intel/AMD | `USBloom-0.1.1-windows-x64.zip` |
| Windows · Arm | `USBloom-0.1.1-windows-arm64.zip` |
| Linux · Intel/AMD | `USBloom-0.1.1-linux-x64.tar.gz` |
| Linux · Arm | `USBloom-0.1.1-linux-arm64.tar.gz` |

Extract ZIP/tar.gz packages and open the executable inside. Linux builds
require glibc 2.39 or newer; see the included installation notes.
For macOS, drag USBloom into Applications. If opening is blocked:

```sh
xattr -dr com.apple.quarantine /Applications/USBloom.app
```

macOS has real-hardware validation. Windows and Linux ARM64 builds have
VM startup checks; physical USB passthrough and hardware hotplug remain
unverified. x64 builds are checked in CI without interactive validation.

### Source and integrity

All packages are built from `USBloom-0.1.1-source.tar.gz`, which includes
locked dependencies and supports offline Cargo builds. `SOURCE_REVISION`
identifies the commit; `SHA256SUMS` covers every release asset.
Each package includes the GPL license and third-party notices.
